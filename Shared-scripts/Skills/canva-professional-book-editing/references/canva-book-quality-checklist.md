# Canva Book Quality Checklist

Use this checklist when editing a book in Canva.

## Cover Checklist

1. exact trim or full wrap size is correct
2. bleed and safe areas are locked before layout work starts
3. front cover has one dominant title hierarchy
4. subtitle is short and readable
5. back cover has a clear barcode-safe box
6. no weak decorative clutter
7. no text shadows or low-contrast text
8. cover still reads at thumbnail size

## Interior Checklist

1. fonts are readable at print size
2. margins are consistent across repeated pages
3. puzzle or activity zones are not crowded by decorations
4. repeated templates stay visually consistent
5. exported PDF is proofed at 100 percent zoom

## Asset Handling Checklist

1. use saved project art, not temporary downloads
2. keep editable Canva templates separate from final export files
3. record final export locations in the project docs
4. if AI art changes, refresh the Canva export rather than editing around outdated assets
