# Canva Interior Quality

Use this skill when the interior must look and feel professional enough to drive better reviews, repeat purchases, and stronger buyer trust.

## When To Use

- improving Canva interiors for puzzle books or activity books
- cleaning template drift across repeated pages
- strengthening readability for kids, hobby, or elder-focused interiors
- reviewing page consistency before export
- moving from merely functional pages to commercially credible pages

## Core Rule

Interior quality is not decoration.
It is readability, consistency, print safety, and ease of use across the full page run.

## Inputs To Gather First

1. trim size
2. page count target
3. audience age or reading profile
4. repeated page types
5. data source files such as CSV or JSON page plans
6. current Canva template or checklist

## Quality Workflow

### Route A: Template Integrity

1. Use one master template per repeated page type.
2. Fix the master template before touching individual pages.
3. Keep margins, title bands, word lists, and grid blocks consistent.

### Route B: Readability

1. Keep body text and puzzle text high contrast.
2. Use fonts that are easy to print and easy to scan.
3. Avoid decorative fonts in functional reading zones.
4. Keep visual hierarchy stable across all repeated pages.

### Route C: Layout Discipline

1. Keep decorative elements out of the activity zone.
2. Do not let one page become noticeably denser than the next.
3. Keep solution pages clean even when multiple blocks share one page.
4. Remove clutter before reducing type size.

### Route D: Export Review

1. review pages at 100 percent zoom
2. review a few pages as if printed
3. confirm the page count matches the book plan
4. export only after consistency holds from first page to last

## Audience Rules

- kids books: friendly but disciplined, simple instructions, bold readable labels
- hobby books: calm and organized, never flimsy or novelty-heavy
- elder-focused books: prioritize large readable type, strong contrast, and clean spacing over decorative style

## Output Contract

A complete run should leave behind:

1. a project-local interior quality spec or checklist
2. a stable Canva template approach for repeated pages
3. a print-ready export decision based on consistency and readability
