# Canva Interior Quality Checklist

Use this checklist before exporting a Canva interior.

## Template Checks

1. one master template exists for each repeated page type
2. title bands and footer positions are consistent
3. margins are stable across the book

## Readability Checks

1. functional text is high contrast
2. puzzle or activity text is easy to scan
3. decorative fonts are not used in reading-heavy zones
4. grouped solution pages remain readable

## Consistency Checks

1. no page feels noticeably more cramped than surrounding pages
2. solution pages match each other visually
3. word columns and grid blocks align consistently

## Export Checks

1. page count matches the book plan
2. export reviewed at 100 percent zoom
3. final PDF looks intentional from first page to last
