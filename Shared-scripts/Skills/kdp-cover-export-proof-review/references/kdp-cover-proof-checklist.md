# KDP Cover Proof Checklist

Use this checklist on every final cover export.

## File Checks

1. exported as `PDF Print`
2. saved inside the project
3. full-wrap dimensions match the KDP spec
4. bleed and trim are correct
5. spine handling matches the real page count and width

## Visual Checks

1. title reads clearly at thumbnail size
2. the hero object is still obvious
3. back cover is calm and readable
4. barcode box is clean
5. no accidental guide layers remain
6. no stretched or low-resolution art appears

## Decision Check

Only replace the old cover export if the new Canva export is clearly more professional, more giftable, and more commercially credible.
