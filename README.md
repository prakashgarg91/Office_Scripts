# Office_Scripts

Reusable VBA, Power Query, and Office Script automation bundles for business-office workflows.

## Current Delivery Target

**ExcelReportPipeline** — automated data import, transformation, and report distribution for recurring business reports.

- **Input:** raw data from CSV, other workbooks, or databases
- **Transform:** Power Query M scripts + VBA orchestration
- **Output:** formatted Excel reports, distribution via email/SharePoint
- **First slice:** `src/bundles/excel-report-pipeline/`
